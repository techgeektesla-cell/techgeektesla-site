0. Read this first (60 seconds)

Full Self-Driving (Supervised) is a driver-assist feature. Tesla’s own language: it does not make the vehicle autonomous. You stay attentive. You stay ready to take over. The cabin camera watches you. Devices that fake occupancy or attentiveness can get the feature shut off for good.

This checklist is for owners who intend to supervise. If you want hands-off, sleep, or a jailbreak, stop here. That is not what this is.

Software moves. Menu names shift. If your car does not show a line below, skip it — do not hunt for a hidden flag. Check Tesla’s in-car release notes and the owner’s manual for your software version.

4. Speed Profile — pick one on purpose

Tesla: FSD (Supervised) sets speed from your profile + speed limit + surrounding traffic (plus nav / fleet historical data). The right scroll wheel up/down changes the profile, not a precise mph offset, on current v14-class builds.

Default Tesla documents: Sloth.

Write what you use:

Profile (Tesla’s description) Use it when…
Sloth At or below the limit. New to FSD. School zones, neighborhood streets, first week with the car.
Chill Slower lanes, minimal lane changes. Dense suburban arterials, bad weather, you are tired of extra passes.
Standard Normal speed, matches traffic flow. Default “I have used this for a month” setting for a lot of owners.
Hurry Faster, more lane changes. Highway with a clock — still supervised.
Mad Max Quicker than Hurry, still more lane changes. Only if you will actually watch the car.

Chicago-owner defaults I actually use as a starting point (yours may differ)

6. Supervised-use habits (this is the part people skip)

Tesla: cabin camera monitors attentiveness while FSD (Supervised) is engaged. Cannot be disabled. Sunglasses still count as “the system is active.”

How to cancel (pick one, do it early)

Also disengages: shift out of Drive, door/trunk open, Automatic Emergency Braking event, seatbelt off / you leave the seat, cameras fail, you blow off attention nags.

Take over immediately on the screen means now — not after you finish the sentence you were saying.

Do this once in an empty lot: engage, cancel with the brake, engage, cancel with the wheel. Muscle memory beats a surprise on I-294.
